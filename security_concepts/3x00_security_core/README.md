# Strategy Layer - Root Cause Analysis

## Introduction

Ce projet consiste à analyser une cyberattaque au niveau **conceptuel et stratégique**, plutôt que de simplement résoudre des problèmes techniques.

## Context

**Client :** ApexFin Global, une entreprise de trading haute fréquence.

ApexFin a subi une attaque ransomware malgré un budget cybersécurité de 5 millions de dollars par an.

La mission est d'effectuer une **Root Cause Analysis (RCA)** afin de déterminer :
- L'impact sur la **CIA Triad** : Confidentiality, Integrity, Availability.
- Quelle partie de l'**AAA** (Authentication, Authorization, Accounting) a échoué.
- Si le **Risk** a été correctement évalué.

## Learning Objectives

À la fin du projet, il faut savoir expliquer :
- La relation entre **Asset, Threat, Vulnerability et Risk**.
- La **CIA Triad** dans une chronologie d'attaque.
- La différence entre **Authentication** et **Authorization**.
- Le rôle de **Accounting** dans la non-répudiation.
- Le calcul de l'**ALE (Annualized Loss Expectancy)**.
